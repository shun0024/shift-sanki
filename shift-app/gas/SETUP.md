# 複数端末で使うためのセットアップ手順

所要時間: 約20分。やることは2つです。

- **A. データ置き場を作る**（Googleスプレッドシート + Apps Script）
- **B. アプリ本体を公開する**（GitHub Pages）→ 会社PC・iPad どちらからも同じURLで開ける

---

## A. データ置き場（Googleスプレッドシート）

1. Googleドライブで **新しいスプレッドシート** を作成（名前は「シフト表データ」など何でも可）
2. メニュー **拡張機能 → Apps Script** を開く
3. エディタに最初から入っている `function myFunction() {...}` を全部消し、同じフォルダの **`Code.gs`** の中身を貼り付ける
4. 上のほうの `const TOKEN = 'CHANGE-ME-to-a-long-random-string';` を、**自分だけが知る長い文字列**に書き換える  
   例: `const TOKEN = 'kobayashi-shift-2026-xYz83kQ';`  
   （半角英数とハイフンのみ。これがパスワード代わりになります）
5. 保存（Ctrl+S）
6. 右上の **デプロイ → 新しいデプロイ**
   - 左の歯車アイコン → 種類で **ウェブアプリ** を選ぶ
   - 説明: 任意（例「v1」）
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - **デプロイ** を押す
7. 「アクセスを承認」→ 自分のGoogleアカウントを選ぶ  
   「このアプリは Google で確認されていません」と出たら → **詳細** → **（プロジェクト名）に移動（安全ではないページ）** → **許可**  
   （自分で作ったスクリプトなので問題ありません）
8. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/....../exec`）をコピーして控える

> **Code.gs を後から直したとき**は、デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン「新バージョン」→ デプロイ、で更新してください。URLは変わりません。

---

## B. アプリ本体の公開（GitHub Pages）

1. https://github.com/ で無料アカウントを作成（メール認証あり）
2. 右上の **+ → New repository**
   - Repository name: `shift-app`（任意）
   - **Public** を選択（Pagesを無料で使うため。データは入っていないので公開して問題ありません）
   - **Create repository**
3. 作成後の画面で **uploading an existing file** のリンクをクリック
4. `shift-app` フォルダの中身を **全部ドラッグ&ドロップ**  
   （`index.html`, `app.js`, `style.css`, `seed.js`, `manifest.webmanifest`, `icon.svg`, `apple-touch-icon.png`, `vendor` フォルダ, `gas` フォルダ）  
   ※ フォルダごとドラッグすれば中身も上がります
5. 下の **Commit changes** を押す
6. リポジトリの **Settings → Pages**（左メニュー）
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**
7. 1〜2分待ってページを再読み込みすると上部に  
   `Your site is live at https://＜ユーザー名＞.github.io/shift-app/`  
   と出ます。これがアプリのURLです。

> **アプリを更新したとき**は、リポジトリの画面で **Add file → Upload files** から変更したファイルをドラッグして Commit するだけです。

---

## C. 各端末での設定

### 会社PC
1. アプリのURLを開く
2. **設定** タブ → **クラウド同期** に、A-8 の URL と A-4 の TOKEN を入力
3. **接続テスト** → 「接続OK」を確認 → **同期を有効にする** にチェック → **保存**
4. 初回は「クラウドに初回アップロードしました」と出ます（今のデータがクラウドに入ります）
5. ブックマークしておく

### iPad
1. **Safari** でアプリのURLを開く
2. 共有ボタン（□↑）→ **ホーム画面に追加** → 追加  
   → ホーム画面にアイコンができ、アプリのように全画面で開けます
3. ホーム画面から開き、**設定 → クラウド同期** に同じ URL と TOKEN を入力 → 接続テスト → 有効にチェック → **保存**
4. 「クラウドから最新データを読み込みました」と出れば完了

---

## 動きかた

- アプリを開いたとき／別タブから戻ってきたときに、クラウドから最新を読み込みます
- 編集すると約2秒後に自動でクラウドへ保存されます（右上のバッジが「同期済み」になればOK）
- 両方の端末で同時に編集した場合は、どちらを採用するか確認ダイアログが出ます
- スプレッドシートの `history` シートに直近30回分の保存履歴が残るので、万一のときはそこから復旧できます

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 接続テストで「トークンが一致しません」 | Code.gs の TOKEN とアプリに入れた文字列が違う。コピペし直す |
| 「応答がJSONではありません」 | URLが `/exec` で終わっていない、または「アクセスできるユーザー」が「全員」になっていない。デプロイをやり直す |
| Code.gs を直したのに反映されない | 「新バージョン」としてデプロイし直していない |
| iPadでフォントが違う | 初回はフォント読み込みに数秒かかります。オフラインだと端末フォントになります |
